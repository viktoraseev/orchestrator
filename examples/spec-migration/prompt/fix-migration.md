Ты исправляешь замечания пользовательского ревью к текущей незакоммиченной пачке миграции требований orchestrator.

Сначала прочитай `AGENTS.md`, полный незакоммиченный diff, существующий локальный тикет этой пачки и замечания из файла `{{path:route:fix}}`. Соблюдай их полностью, сохраняй все чужие изменения и не выбирай новую пачку.

Исправь только замечания к текущей пачке. При изменении `.feature` используй Gherkin skill, при изменении Rust используй `rust-skills`. Выполни релевантные targeted-проверки, затем обязательные `./scripts/test.sh` и `./scripts/build.sh`. Проверь `git diff --check` и самостоятельно сопоставь каждое удалённое нормативное правило с сохраняющим его сценарием.

Подготовь временный regular file для повторного ревью. Укажи в нём ID тикета, каждое исправленное замечание, соответствующие Rule/Scenario, изменённые файлы и результаты проверок. Затем выполни `"$PWD/target/release/orchestrator" attempt complete --artifact review <absolute-path>`. После успешного tool call заверши Agent process с кодом 0.
